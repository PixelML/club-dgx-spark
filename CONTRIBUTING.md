# Contributing

1. Read [AGENTS.md](AGENTS.md) and remove private infrastructure details.
2. Put detailed model evidence in its model-family repository.
3. Add only the compact linked summary here.
4. Label claims as measured, inferred, community-reported, or untested.
5. Run the publication gate before opening a pull request.

Use a Conventional Commit subject without AI attribution. Negative results are welcome when the tested boundary and evidence are clear.
